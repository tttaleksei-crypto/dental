# Система учета стоматологического кабинета

## Функциональность

### Основные модули:
- 📅 Регистратура и расписание
- 👥 Учет пациентов и электронные карты  
- 👨‍⚕️ Управление врачами и специализациями
- 🦷 Прайс-лист услуг
- 📋 Наряд-заказы и расчет ЗП врачей
- 💰 Финансовый учет и отчетность
- 📦 Учет материалов и запасов
- 📊 Аналитика и отчеты

### Интеграции:
- 💳 Онлайн-касса и эквайринг
- 🔄 Синхронизация с 1С
- 🏥 Отчетность в ЕГИСЗ
- 📄 Медицинская отчетность

## Установка

1. Разместите файлы на веб-сервере (Apache + PHP)
2. Создайте базу данных SQLite
3. Запустите инициализацию БД: `/config/init_database.php`
4. Заполните тестовыми данными: `/config/fill_test_data_fixed.php`
