# Инструкция для разработчика

## Архитектура системы

### База данных
- **SQLite** - файловая БД в папке `database/`
- **PDO** - для работы с БД
- **Миграции** - через файлы в `config/create_*_tables.php`

### Безопасность
- Сессии PHP для аутентификации
- Ролевая модель (врач/бухгалтер)
- Валидация входных данных
- Подготовленные запросы (prepared statements)

### Frontend
- **Tailwind CSS** - стилизация
- **Адаптивный дизайн** - для мобильных устройств
- **Иконки** - эмодзи и SVG

## Расширение системы

### Добавление новой таблицы:
1. Создай `config/create_NEW_table.php`
2. Добавь тестовые данные в `fill_test_data_fixed.php`
3. Создай модуль в `api/NEW_module.php`

### Добавление новой роли:
1. Добавь поле в таблицу doctors
2. Обнови `config/auth.php`
3. Создай личный кабинет в `api/ROLE_dashboard.php`

## API endpoints

Все модули доступны через `api/` папку:
- `patients.php` - управление пациентами
- `schedule.php` - расписание записей  
- `finance.php` - финансовые отчеты
- и т.д.

## Интеграции

### Онлайн-касса:
- Модуль: `api/online_cash.php`

### 1С синхронизация:

### ЕГИСЗ:
